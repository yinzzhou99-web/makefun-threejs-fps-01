Dustline Depot: an original round-based tactical FPS in three.js, Counter-Strike in structure and nothing copied. Five attackers against five defenders on a sun-baked depot map with two bomb sites, a mid door choke and container lanes. A full match loop: buy phases with a five-item economy (SMG, rifle, scoped DMR, kevlar, frag grenades), 115-second rounds, a plantable bomb with a 40-second timer and defender defuses, round and match scoring to five. Nine bots plan over a waypoint graph derived from the map's own solids — pushing sites behind the carrier, holding angles, rotating on contact, retaking and defusing — and fight with the same weapon table as the player: headshot multipliers, range falloff, bloom and movement spread that reward stopping to aim. Fixed 60 Hz simulation, synthesised audio, minimap, killfeed and scoreboard; no assets, everything is code.

## Run it

```sh
node serve.ts
```
